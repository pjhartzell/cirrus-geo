    Cirrus¶

    Cirrus is a STAC-based geospatial processing framework built on serverless AWS infrastructure. It supplies the parts that are the same in every processing pipeline — queueing, workflow execution, state tracking, publishing — so you can focus on your processing code. And because inputs and outputs are STAC items, results are immediately ready for ingest into a STAC catalog or use in another Cirrus workflow.

    Cirrus is proven in production. The pipelines that populate Earth Search, Element 84's public STAC catalog of open Earth observation data, run on Cirrus for both daily ingest and full-catalog reprocessing.
