    Deployment¶

    Programmatic interface to a deployed Cirrus instance, the same layer the Cirrus CLI is built on. Requires the cli extra (pip install 'cirrus-geo[cli]').

    run_workflow ¶

    run_workflow(
    payload: dict,
    timeout: int = 3600,
    poll_interval: int = WORKFLOW_POLL_INTERVAL,
) -> tuple[int, dict[str, Any]]

    Parameters:

    Name Type Description Default
    deployment Deployment

    where the workflow will be run.

    		 required
    payload str

    payload to pass to the deployment to kick off the workflow.

    		 required
    timeout Optional[int]
    • upper bound on the number of seconds to poll the deployment before considering the test failed.
    		 3600
    poll_interval Optional[int]
    • seconds to delay between checks of the workflow status.
    		 WORKFLOW_POLL_INTERVAL

    Returns:

    Type Description
    tuple[int, dict[str, Any]]

    dict containing output payload or error message
