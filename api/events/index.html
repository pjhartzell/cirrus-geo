    WorkflowMetricLogger ¶

    WorkflowMetricLogger(
    logger: Logger | None = None,
    log_group_name: str = "",
    batch_size: int = 1,
)

    Bases: BatchHandler[WorkflowEvent]

    A class for surfacing workflow state changes to Cloudwatch Logs, and retrieving metrics from Cloudwatch Metrics.

    This defaults to a batch_size of 1, to make all logs immediate. This is because we can't guard against a lambda timing out an execution, and preventing us from sending the last batch of messages on exit.

    WorkflowEventManager ¶

    WorkflowEventManager(
    logger: Logger | None = None,
    statedb: StateDB | None = None,
    eventdb: EventDB | None = None,
    metric_logger: WorkflowMetricLogger | None = None,
    batch_size: int = 10,
)

    A class for managing payload state change events, including: 1. storage of state (DynamoDB) 2. storage of data for workflow metrics (Timestream) 3. notifications of Cirrus decisions and/or workflow status changes (SNS).

    Other than announce, which is used for announcement of malformed payloads/messages, the public functions here are aimed for use in the process and update-state lambdas.
