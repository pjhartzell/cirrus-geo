    Command reference¶

    Generated from the cirrus command tree. All commands accept --help for this same information at the terminal. Subcommands may be abbreviated to any unambiguous prefix, and mgmt is an alias for manage.

    cirrus¶

    CLI for running operational commands against cirrus deployments

    Usage:

    cirrus [OPTIONS] COMMAND [ARGS]...

    Options:

    Name Type Description Default
    --profile text AWS CLI profile name to use for session Sentinel.UNSET
    --region text AWS region name to use for session Sentinel.UNSET
    -v, --verbose integer range (0 and above) Increase logging level. Can be specified multiple times. 0
    --help boolean Show this message and exit. False

    Subcommands

    • list-deployments:
    • manage:
    • payload:
    • version: Cirrus CLI version

    cirrus manage¶

    Commands to run management operations against a cirrus deployment.

    Usage:

    cirrus manage [OPTIONS] DEPLOYMENT_NAME COMMAND [ARGS]...

    Options:

    Name Type Description Default
    --iam-arn text N/A Sentinel.UNSET
    --help boolean Show this message and exit. False

    Subcommands

    • call: Run an executable, in a new process, with the deployment environment
    • exec: Run an executable with the deployment environment vars loaded
    • get-batch-logs: Get CloudWatch logs for a Batch job
    • get-execution: Get basic workflow execution details using its ARN or its input payload ID
    • get-execution-events: Get a workflow execution's event history using its ARN or its input payload ID
    • get-execution-input: Get a workflow execution's input payload using its ARN or its input payload ID
    • get-execution-output: Get a workflow execution's output payload using its ARN or its input
    • get-input-payload: Get an input payload from S3 using its ID
    • get-input-payloads:
    • get-lambda-logs: Get CloudWatch logs for a Lambda invocation
    • get-output-payload: Get an output payload from S3 for an input payload ID
    • get-state: Get the statedb record for a payload ID
    • get-workflow-definition: Get a workflow's state machine ASL definition using the workflow name
    • invoke-lambda: Invoke lambda with event (from stdin)
    • list-lambdas: List lambda functions
    • migrate: Migrate state DB and payload bucket to cirrus v2 compatible schema
    • process: Enqueue a payload (from stdin) for processing
    • query:
    • run-workflow: Pass a payload (from stdin) off to a deployment, wait for the workflow to finish,
    • show: Show a deployment configuration
    • template-payload: Template a payload using a deployment's vars

    cirrus manage DEPLOYMENT_NAME get-input-payloads¶

    Retrieve a filtered set of payloads from S3 via querying the state DB for matching payload IDs Rerun flag alters payloads to enable rerunning payload

    Usage:

    cirrus manage DEPLOYMENT_NAME get-input-payloads [OPTIONS]

    Options:

    Name Type Description Default
    --rerun boolean Rerun payloads False
    --error-prefix text The error prefix to filter on Sentinel.UNSET
    --limit integer range (between 1 and 50000) Maximum number of payloads to return Sentinel.UNSET
    --since since Time filter. Integer followed by a unit letter (d=days, h=hours, m=minutes), e.g., '7d', '24h', '30m' Sentinel.UNSET
    --state choice (PROCESSING | SUCCEEDED | FAILED | INVALID | ABORTED | CLAIMED) Execution state to filter on Sentinel.UNSET
    --collections-workflow text The collections-workflow field to filter on Sentinel.UNSET
